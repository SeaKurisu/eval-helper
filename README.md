# 一键评教助手 (Eval Helper)

学评教一键批量评价的浏览器油猴脚本。直接调用评教接口提交，不用一门一门打开弹窗、等 60 秒倒计时。12 门课从十几分钟缩短到 1 分钟左右。

目前支持：**重庆邮电大学 教务在线 · 学评教（2025 版）**。脚本按“站点适配器”设计，其他学校的评教系统可以通过新增一个适配器接入。

## 安装

1. 安装浏览器扩展 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. Chrome 需要在 `chrome://extensions` → 篡改猴 → 详细信息 中打开 **允许用户脚本**（没有这个开关时，打开右上角的“开发者模式”）。
3. 点击安装：**[eval-helper.user.js](https://raw.githubusercontent.com/SeaKurisu/eval-helper/main/eval-helper.user.js)**，在篡改猴弹出的页面点“安装”。

不熟悉电脑的同学请看图文版指南：[docs/index.html](docs/index.html)（开启 GitHub Pages 后可直接在线浏览）。

## 使用

打开学评教页面，右下角会出现绿色的 **一键评教** 按钮：

- **打分方式**：统一分数，或在一个区间内随机；可选“避免全部同分”。
- **评语**：每行一条模板，随机选用；留空则不填。
- **预览** → **先提交 1 门**（确认成功）→ **全部提交**。

提交后不可修改，每次提交前都会弹窗确认。

## 工作原理

| 发现 | 做法 |
|---|---|
| 60 秒倒计时只是前端 `setInterval`，按钮 `disabled: p > 0` | 不走弹窗，直接调用接口提交 |
| 接口靠浏览器 Cookie 鉴权，无签名 | 在页面内 `fetch`，沿用当前登录状态 |
| 每门课需评价 2 次 | 读取课程列表的 `pjNum`，只补交未完成的次数 |
| 服务端是否校验停留时长未知 | 若提交被拒且提示与时间有关，自动等到取题后 60 秒再重试 |

另带一个可选的“加速页面自带倒计时”开关，用于手动评价时把 60 秒压缩到不到 1 秒。

## 适配其他学校

脚本分为通用引擎（打分策略、重试、面板）和站点适配器两层。新增一个学校只需在 `PROFILES` 里加一项，并在头部加对应的 `@match`：

```js
{
  id: 'your-school',
  name: '某某大学 学评教',
  match: /你的评教页面路径/,
  requiredTimes: 1,          // 每门课需要评价几次
  minWaitSec: 60,            // 服务端若校验停留时长
  async listTasks() {},      // -> [{ key, title, done, remaining, raw }]
  async getForm(task) {},    // -> { items: [{ id, label, group, max }], hasMemo, fetchedAt }
  async submit(task, form, answers, memo) {}, // -> { ok, msg }
  isTimeError(msg) {},       // 服务端是否因停留时间不足而拒绝
}
```

找接口的方法：打开浏览器开发者工具的 Network 面板，手动评一门课，记下“课程列表”“评价题目”“提交”三个请求的地址和数据格式。欢迎提交 PR。

## 声明

- 脚本只在你自己的浏览器中运行，不读取账号密码，不向第三方发送任何数据。
- 评教分数会影响教师考核，请按真实感受打分。使用前请了解所在学校的相关规定，使用后果由使用者自行承担。
- 本项目与任何学校官方无关。
